# English Adventures — prompts para a próxima leva de arte (gerar no ChatGPT)

Cole cada prompt separadamente (um por imagem). Se o ChatGPT permitir anexar uma
imagem de referência, anexe um print da tela inicial atual do app (a arte com
Leo/Mia/Buddy/Luna) para ajudar a manter os personagens consistentes — mas os
prompts abaixo já descrevem cada personagem em detalhe, então funcionam sozinhos
também.

Depois de gerar, me envie os arquivos (arraste no chat ou link do Drive, como da
última vez) que eu recorto/redimensiono e já deixo funcionando nas telas certas.

Nomeie os arquivos como sugerido abaixo — assim eu sei onde cada um entra.
