# Passo a passo completo — subir tudo para o seu domínio Este guia cobre: (1) o backend que substitui o Firebase, (2) todas as páginas que precisam apontar para esse backend, (3) o novo curso "English for Job Interviews" nos Cursos Extras, e (4) as páginas de teste (test1.html a test7.html) que agora são hospedadas no seu domínio em vez do GitHub Pages. --- ## Parte 1 — Backend (PHP + MySQL) ### 1.1 Criar o banco de dados hPanel → **Bancos de Dados → Bancos de Dados MySQL** → criar um banco novo e um usuário novo. Anote **nome do banco**, **usuário** e **senha**. O host é quase sempre `localhost`. ### 1.2 Criar a tabela hPanel → **Bancos de Dados → phpMyAdmin** → selecione o banco criado → aba **Importar** → escolha o arquivo `api/schema.sql` → **Executar**. ### 1.3 Enviar os arquivos do backend Pelo **Gerenciador de Arquivos** (ou FTP), envie a pasta `api/` inteira para dentro de `public_html/`, de forma que fique: `public_html/api/portal.php`, `public_html/api/db.php`, `public_html/api/config.php`. ### 1.4 Editar `api/config.php` Abra pelo editor do Gerenciador de Arquivos e preencha com os dados do passo 1.1, e invente uma `api_key` longa e aleatória: ```php return [ 'db_host' => 'localhost', 'db_name' => 'SEU_BANCO_AQUI', 'db_user' => 'SEU_USUARIO_AQUI', 'db_pass' => 'SUA_SENHA_AQUI', 'api_key' => 'INVENTE_UMA_CHAVE_LONGA_E_ALEATORIA', ]; ``` ### 1.5 Testar o backend No navegador, acesse (trocando `` e ``): ``` https:///api/portal.php?action=pull_all&key= ``` Esperado: `{"ok":true,"docs":{}}`.
